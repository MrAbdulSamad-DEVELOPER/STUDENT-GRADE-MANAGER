# STUDENT-GRADE-MANAGER

A small Python tool to manage student marks, averages, letter grades and class rankings.

## Features

- Add students and record marks (0–100)
- Average marks per student
- Letter grades (A / B / C / D / F)
- Class ranking (highest average first)
- Class average

## Run it

```bash
python grades.py
```

## Run the tests

```bash
python -m unittest test_grades.py -v
```

## Project structure

- `grades.py` — the GradeManager class and a demo
- `test_grades.py` — unit tests (8 tests)
